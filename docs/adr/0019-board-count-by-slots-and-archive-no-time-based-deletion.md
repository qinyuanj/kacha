# 画板位限制可编辑数量，画板不按时间删除

画板位限定可同时持有的可编辑画板数量，满位后拒绝新建，已有画板仍可编辑。归档画板只读且不占画板位，有空位时可取消归档或复制为新画板。画板及归档内容不按时间自动删除。

自动挑选最近几块画板锁定会打断正在进行的工作；按闲置时间删除又会删掉需要回看的内容，因此由用户明确归档或删除。画板体量只用于整理提示，不改变任务成败。

本机画板位由本机存储层执行：新建、复制、导入与取消归档都受 20 位约束，归档画板只读且不占画板位，画板与归档不按时间删除。体量度量与整理由本机存储层按唯一任务目录与独立图片量出，桌面端口据此显示体量与整理入口（#158）；读不出时按未知处理，不当作 0。
