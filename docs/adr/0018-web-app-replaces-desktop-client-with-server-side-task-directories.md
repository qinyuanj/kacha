# Web 版取代桌面客户端，任务目录放在服务端

2026-11-04 决定：Kacha 改为部署在 lzxsvn 上的 Web 应用，桌面客户端立即退役，已安装的 `v0.3.x` 可继续使用但不再发布更新。`client/src-tauri` 改造为 `server/`（Rust + axum），移除 Tauri 依赖，`store.rs`、`board_pack.rs`、`image_info.rs` 等与 Tauri 无耦合的模块原样迁入；前端 `client/src/shell` 的 IPC 改为 HTTP。旧桌面代码与 `packaging/` 从 main 删除，靠 tag `v0.3.2` 找回。本决定取代 ADR 0007、0008、0016、0017。

任务目录与画板仍是 ADR 0010 的形状，但存放在服务端按用户隔离的用户数据根下，用户不能自己设置位置。没有登录流程，也没有准入名单：用户在页面粘贴自己的 new-api API 密钥，服务端先向网关验证密钥有效，再以密钥指纹（哈希）作为用户身份并发放 7 天会话 cookie（页面加载结果图的请求只能靠 cookie 认人）；服务端只存指纹，不存密钥。密钥只能读到令牌名与额度，解析不出 new-api 用户（2026-11-04 实测），而生成本就需要用户自己的密钥，再加账号登录是多余的。预期规模约 30 人。生成请求与任务队列仍在浏览器里，由浏览器直接调用网关（网关 CORS 已放开）；结果图所在的对象存储不允许跨域（实测无 `Access-Control-Allow-Origin`，预检 403），因此浏览器把结果地址交给服务端，由服务端只从已知对象存储域名下载并流式写入任务目录。

## Considered Options

- **发布到学习站（qinyuanj/learning，`lzxsvn:3002`）**：否决。该站只托管静态文件、没有后端，HTTP 下浏览器拿不到 `crypto.subtle` 与本机目录，任务目录只能落进可被清除的 IndexedDB；且全站同源，能往 learning 推内容的人都能读到 API 密钥。
- **桌面版与 Web 版并行，抽共享 crate**：否决，用户决定不再维护桌面版。
- **桌面程序内嵌 HTTP 服务**：否决。Tauri 按带窗口、跟随用户登录的进程设计，服务生命周期绑在 GUI 上，崩溃或更新会让所有人断线。
- **任务队列放服务端**：否决。要重写任务队列并让服务端保管密钥；代价是关闭或刷新页面时执行中的任务变为已中断。

## Consequences

- HTTP 仍只限可信内网或 VPN（ADR 0003），且对所有用户生效；离开内网只能走 VPN。
- 服务端不做备份：用户数据根是唯一副本，丢失时由用户自己导出的画板包与下载的结果兜底；页面顶栏常驻提示「服务端不备份；60 天未使用的数据可能被清理，请定期导出画板包」，README 与迁移说明同样写明。身份只是密钥指纹，没有联系方式，无法逐个通知。
- 磁盘：不设配额；剩余空间低于 20 GB 时拒绝新的写入并提示联系管理员，服务端日志每天记录各用户数据根的大小。
- 清理（ADR 0010「任务目录不删」的服务端例外）：只清闲置用户（连续 60 天无访问的用户数据根，多为换密钥留下的旧指纹）与未引用任务目录（该用户所有画板都不再引用且建立超过 30 天）；仍被画板引用的结果一律不按时间删除。管理员在 lzxsvn 上手动运行 `kacha-server cleanup --dry-run` 预览候选目录、大小与最后访问时间，确认后执行；删除先移入回收区保留 14 天再彻底删除，磁盘紧急时 `--purge` 跳过回收区。不做自动清理。页面显示当前用户用量，用户可按同一规则自行清理自己的未引用任务目录，删除前列出清单并确认。
- 迁移：Web 版保证能导入 `v0.3.x` 导出的画板包（含图层文件与 `layers.json`）；Gitea Release 页与 README 指向 Web 地址并写明迁移步骤。桌面版收不到停更通知。
- 第一版保留画板、生成、画板包与结果下载（单张与整板 zip），去掉自动更新与诊断包；系统对话框改为浏览器上传 / 下载。
- 并发：同一画板多页面编辑时，保存带版本号，过期写入返回 409 并提示重新载入，不自动合并；并发上限按页面各自计算，靠网关限流兜底。
- 服务端接口只接受相对于用户数据根的路径并拦截越界；服务端按 512 MB 内存预算设计：单文件请求体上限 64 MB，画板包上传流式落临时文件，全局最多同时处理 4 个大请求。
- 部署：在开发机 release 编译，复制产物到 lzxsvn（Windows，8 GB），注册为 Windows 服务，单进程托管前端静态文件，使用独立端口；版本号以 `server/Cargo.toml` 为准并显示在页面上。
- 身份即密钥：用户换密钥就被视为新用户，看不到原有数据，需由管理员手动把旧数据目录挪到新指纹下；new-api 开放注册，任何持有有效密钥的人都能使用 Kacha。
