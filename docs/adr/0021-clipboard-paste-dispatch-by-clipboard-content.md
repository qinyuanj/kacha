# 复制看选区，粘贴看系统剪贴板

Ctrl+C 选中单张参考图或结果时复制图片，其余选区复制节点并写入节点标记文本。Ctrl+V 先判断节点标记，命中时粘节点，否则系统剪贴板有图则落成参考图。只用应用内剪贴板或只按图片优先都会把旧内容误当作当前意图，因此两者都不采用。

桌面通过 Go 原生系统剪贴板读写文本与 PNG，不依赖 Web Clipboard 权限。节点标记只在当前运行实例的内存剪贴板有效，标记命中但内存内容已丢失时提示重新复制。粘图落入数据根的导入参考图，一次粘贴一个撤销步，不自动接线。

复制图片不改画板、不构成撤销步，也不改内部节点剪贴板。格式不受支持或内容损坏时明确失败并给另存为入口；系统剪贴板被占用时给可重试失败。真实系统剪贴板与外部软件互操作需 Windows 真机验证，合成事件不能代替。
