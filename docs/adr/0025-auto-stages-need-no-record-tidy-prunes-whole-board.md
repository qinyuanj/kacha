# 自动划分阶段由候选节点决定，整理动作可作用整板

此决定约束保留的整理核心，当前桌面整理入口尚不可用。

自动划分只处理未进入任何阶段、且本版本认识的节点。每次生成尝试由任务节点、经系统连线归属的结果列，以及直接输入的提示词和参考图组成，成员少于两个时不建阶段。结果的 `task_id` 是提交编号，不能拿它与任务节点 ID 比较归属。

不记录已经划分过的标记：候选筛选天然让重复点击成为空操作，也允许之后新长出的尝试继续被划入。没有画板变化就没有撤销步，一次划分只有一个撤销步。进入整理只是查看，不自动写阶段。

整板收掉未定稿复用同一变更，传入全部阶段 ID；逐阶段操作仍可用。两者都先确认、一步撤销，只移除未定稿且未被下游使用的结果节点，不直接删任务目录。建议保留只作提示，不自动定稿，也不改变收掉判定。
