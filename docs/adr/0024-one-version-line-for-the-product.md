# 产品版本由桌面清单唯一声明

Kacha 只有一个产品版本，唯一声明在 `mygo.config.ts`。构建入口读取该版本写入桌面产物，更新说明与其一致；不另设独立版本文件或第二张清单。

[更新说明](../release/changelog.md) 先写当前版本，再保留可查历史版本，界面从同一份文档显示更新内容。一级标题使用产品版本号并按新在前排列，同号只保留一节；二级标题按新增、改进、修复分组，当前版本至少有一条用户可见变化，历史条目保留发布当时语境而不作为当前能力证据。来源与核对结果单独记录，不另设版本线。门禁拒绝缺当前说明或版本不一致的构建；完整索引由守护测试检查。

画板格式、画板包格式和构建工具版本各自独立，不随产品版本变化。源码运行可显示 `dev`，产物上的版本须以打包结果验证。
