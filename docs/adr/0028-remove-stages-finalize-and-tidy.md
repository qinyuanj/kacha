# 移除阶段、定稿、整理与体量提醒，不设替代

画板曾围绕「迭代分组与减负」提供一整套能力：阶段（框定并命名一段迭代、收起、增删成员、按候选节点自动划分）、定稿（标记要留下的生成结果，重开仍在）、整理模式（查看画板与各阶段体量、收掉未定稿结果、把阶段移出为新画板），以及引导用户去整理的体量提醒。

2026-11-24 owner 决定整套移除，不做替代，也不保证旧客户端能打开新画板（spec #248）。产品版本升到 1.7.0，移除在 1.7.0 交付。

## 为什么移除

这套模型不再换来它要付的维护面：它占住了画板变更闭集里与这些能力绑定的成员——建阶段、重命名、加入、移出、收起、展开、删除、标记定稿与取消、收掉未定稿、自动划分、移出为新画板；还有一整套阶段层界面、一条跨 Go 与 TypeScript 的度量端口和约 300 条客户端用例（spec #248 的 Problem Statement）。

它想解决的问题也不再存在：画板体量不再是需要用户主动减负的约束，迭代也不再按「阶段」组织。继续维护一套没有对应问题的模型，比删掉它的代价更大。移除按 spec #248 的 Implementation Decisions 分票实施：#249 删动作与文案入口，#250 删阶段框与定稿徽标，#251 删「移出为新画板」与画板位预检，#252 删整理模式、体量提醒与度量端口，#253 收缩画板格式并加首次改写前的备份，#256 清掉变更联合类型与核心变换里的残留。

## 旧数据怎么处理

- 画板里的阶段是一组顶层记录（名字、成员、收起状态），定稿是结果节点上的布尔标记，`source_board` 是参考图节点上「从哪里移出」的标记。三者都是可选字段，只存在于 TypeScript 侧；Go 侧从未读取，只当不认识的 JSON 跳过。
- 移除后按「认识的、但被丢弃的」键处理：解析时认下并丢弃，写出一律不再包含，也不再提供读取器。不能把它们从认识键名单里删掉——那样会被当成未知字段原样写回，旧画板会一直带着已移除的字段（`client/src/core/board.ts` 的 `NODE_KEYS` 与注释）。
- 格式版本保持 2：旧画板本来就是 v2，字段可选，不制造 v3 让旧读端拒绝打开（#253）。
- 第一次改写前备份：本地存储写画板前，若目标文件已存在，先把原文件复制成同目录下的同名 `.bak`；`.bak` 已存在时不覆盖（`desktop/internal/localstore/localstore.go` 的 `WriteBoard`）。备份只在真正写入时发生一次，不做一次性迁移、不扫描目录。
- 因此这次移除不会顺手毁掉已经做过的取舍记录：想找回旧阶段与定稿，去那份 `.bak`。它只有一份，不是滚动备份；删除画板时主文件与 `.bak` 一起进回收区。

## 为什么没有替代

体量提醒保留的唯一动作是「整理」。整理移除后它没有可执行的出口，留下就是死胡同，所以提醒一起删（spec #248 的移除边界）。画布上不再有「这块画板太大，去整理」之类的提示条，也不再有按画板记忆的整理状态。

不另造一个「轻量整理」或「阶段 2.0」：那等于把刚付过的维护面再付一次，而需求侧没有对应的问题。字节数是事实，照旧显示；把事实显示出来不等于提供一个减负动作。

## 什么没有动

- 归档、20 个可编辑画板位、归档只读与不按时间删除。
- 画板包导入导出、唯一引用计量与清理、回收区恢复。
- 生成能力：文生图、参考图编辑、透明背景与图层拆分。
- 画板列表里每块画板的字节数：字节数是事实信息，不是提醒，照旧显示，越过提醒线的行照旧按档位标出。度量模块因此保留，但只留「整块画板有多少字节」这一半；按节点归属的那一半随整理删除，它原来的另一个读方（跨语言引用识别一致性测试）改指向仍然存在的实现，而不是删掉。
- 桌面壳 features 里归档那一项不动；管整理的那一项从 Go 结构体、JSON 契约、页面能力标识与端口装配里一起消失。
- 历史更新说明：1.5.0、1.3.0 等版本里关于阶段与定稿的条目一字不改，它们记录当时确实有过这些能力（ADR 0024 的单一来源约定）。

## 后果

- 旧画板照常打开、照常编辑，不需要先处理旧数据；1.7.0 保存之后阶段与定稿不再存在（除 `.bak` 里那份）。
- 旧客户端打开 1.7.0 保存过的画板时不再有阶段与定稿，这条不承诺兼容（#248）。
- 仓库里不留无人调用的导出、无人读的字段与只为这些特性存在的测试；留下的是邻居契约的唯一证据（归档只读白名单、导入包仍可计量、本机度量方法的结果形状），已随动作闭集更新。
- 词表保留「整理」「阶段」「定稿」「建议保留」四条原条目，标注「已移除（2026-11-24）」并指向本文；「画板体量」条里「体量提醒只引导整理」的表述按同一日期更正，历史说法不抹掉。
- ADR 0019 与 ADR 0025 的相关表述被本决定取代，原文不改，只加「已被取代」注记（2026-11-24）。
- `docs/release/ACCEPTANCE-165.md` 里把「阶段与定稿整理」列为通过的两条验收行加日期注记指向本文：那两行在写下时确实通过，不判失败。
