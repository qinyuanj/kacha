# 单机优先的 Windows 桌面客户端

Kacha 仅提供单机优先桌面客户端。Go / MyGo 负责窗口、数据根、文件和系统剪贴板，React / React Flow 保留画板核心。MyGo 和配套 CLI 固定版本，升级单独验证。客户端不启动 Rust 进程，也不依赖远端应用服务。

数据根由客户端管理，一台电脑一份。打开、编辑和组织画板不需要网络或登录，API 密钥不决定本机画板身份。数据迁入只通过用户手动导出的画板包，不连接旧服务、不扫描旧数据目录。

原生能力经前端壳端口进入，UI 不直接依赖 MyGo 绑定。桌面启动失败应报告本机错误，保留在桌面运行路径内。生成等模型调用是需要联网的独立能力，尚未接入时明确标为不可用。

图片由 Go 注册的 `kacha` 自定义协议提供给 WebView2，页面通过 `http://kacha.localhost/<相对路径>` 读取。WebView2 不允许应用 HTTP 页面直接读取 `file://` 子资源，因此不能以文件 URL 代替该协议。

真实剪贴板操作需在已解锁的 Windows 交互会话中验收。升级 MyGo 时重新核对剪贴板占用错误的结构化映射及 PNG 透明度互操作，不用合成事件代替外部软件验证。
