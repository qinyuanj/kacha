# 一个生成任务恰产生一个生成结果

每个生成任务有独立的任务目录与成败结局。Qwen 固定发送 `n = 1`；Flash 不发送 `n` 或组图参数，普通响应必须恰好有一张有效图片。图层拆分的底图与图层共同组成一个结果，任一图层失败即整体失败。

多张需求由份数展开成多个独立任务，各挂一个结果节点，实际份数不超过客户端并发上限；生成变体固定一份。成功的任务照常落结果，失败的任务不自动补跑。这样无需引入单任务部分成功语义，也避免依赖网关未知的单次多图契约。

桌面客户端按这套规则执行生成（#153 起接通网关、任务目录与结果节点）：一份一张结果，多份各自排队、各自成败。取消只让客户端不再等待这一份、不再落它的结果，不承诺网关停止计费；失败与取消都不自动补跑。
