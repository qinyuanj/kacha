# 质量工具使用单个 uml-viewer 二进制

CRAP、重复与变异检查调用 `uml-viewer crap|dry|mutate`。本机先查 `UML_VIEWER_BIN` 绝对路径，再查 DSH 插件 `dsh-uml-viewer/current.json` 指向的版本目录；两处都没有时明确失败，不从 PATH 猜同名程序。

2026-11-20 起变异测试没有调用方（见 ADR 0020）：门禁只跑 `crap` 与 `dry`，`mutate` 子命令与 `--copy` 约束保留给将来重新启用时用。

CI 使用固定版本和 SHA-512 完整性值的平台包，仅提取所需二进制，验证失败即退出。本机插件升级由包装脚本测试核对报告契约。

Windows 变异测试（当前未启用，见 ADR 0020）只复制被运行的包，包外的契约夹具、更新说明和桌面版本清单由包装脚本显式传 `--copy`。工具不支持该开关时明确失败，避免在不完整副本里给出结果。未覆盖变异点从指标快照读取，只统计本次改动文件。

变异副本也不是 OS 隔离边界：使用绝对路径、注册表或网络的测试仍能影响副本之外。具体工具发现和命令见 [构建说明](../../packaging/README.md)。
