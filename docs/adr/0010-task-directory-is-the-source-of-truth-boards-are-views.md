# 任务目录为真源，画板为视图

任务目录位于 `数据根/<UTC 日期>/<task_id>/`，保存任务记录、参考图快照、结果图、图层与结局记录。每个文件写入一次，此后不可变。画板只保存节点、连线与展示所需的记录子集，用相对路径和 `task_id` 引用任务目录，冲突以任务记录为准。

删除画板或结果节点不直接删除任务目录。图片缺失时节点保留占位，用户可在数据根内按哈希或任务编号重新定位。把图片内嵌或移入画板文件会复制共享结果、破坏追溯链，并把画板撑成大文件，因此不采用。

任务目录的读写与兼容规则由前端核心集中定义；本机导入器需要核对包内任务记录和参考图哈希，守住文件完整性与路径边界。画板包不改变任务目录的真源地位（ADR 0013）。
