# 画板包是交换物，任务目录仍为真源

画板包是一个 `.ugcpack` zip 文件，包含清单、一块画板、其直接引用的完整任务目录及导入参考图。独立参考图按内容去重放入 `导入参考图/`，画板路径改写为相对路径。导入只写入本机数据根，拒绝越界、未知包版本与损坏内容。

包格式 v2 按内容去重，重复路径通过 `manifest.json` 的 `duplicates` 指向包内实存条目，禁止链式映射；导入还原内容，v1 包仍可读。已有任务相同则跳过，身份内容冲突则不覆盖；同名画板自动改名。失败或取消后已移入的完整任务目录保留，未完成画板不提交。

画板文件不自包含。单 JSON 内嵌 base64 会增加体积，也失去可直接排查的目录结构；沿来源记录递归打包全部上游会过度扩大包，因此只打包画板直接引用的任务目录。用户通过手动导出的包迁入或交接数据。当前桌面导入与导出都已接通：导出按同一格式与去重规则在本机打包，目标由系统对话框选择，失败与取消不留半成品；导入规则保持不变。
