# 画板变更经唯一入口应用

前端核心用封闭联合类型表达用户变更、系统变更和视图变更，由纯函数计算新画板、撤销步与提示。界面仅通过 `apply(画板键, 变更)` 写画板，调用方不能自选变更类别、撤销描述或归并键。用户变更构成撤销步，系统与视图变更不构成。

除视图变更外，变更共用图片端口同步和自动宽高比重算管线。运行期锁定作为后置不变量检查，避免每个入口各写守卫而漏掉一种动作；系统写入与明确连同取消的删除按规则豁免。

确认框、取消任务、选文件、图片尺寸和哈希读取在界面先完成，再把事实交给核心。核心保持同步和纯，撤销重做通过 ADR 0012 的系统状态合并处理。原始 updater 闭包会让调用点自行声明语义，难以验证不同入口行为一致，因此不保留。
