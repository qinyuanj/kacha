# 快照式撤销排除系统变更

撤销和重做按画板快照记录，每步对应一个用户意图，历史按画板独立、仅存内存、最多 100 步。生成结果、提交记录与异步补算不构成撤销步，也不清空历史；视口、标题与上次模型选择不进撤销。

回到旧快照时合并当前仍应保留的系统结果及连线，锁定任务与其输入也保留当前状态，避免撤销改变已提交输入。父任务不在快照时，相应结果节点随之消失，任务目录文件不受影响。自动宽高比随用户变更同步计算时进入同一个快照，迟到图片尺寸引发的补算属于系统变更。

快照无需为每个动作写逆操作；排除系统变更可避免 Ctrl+Z 抹掉刚生成的结果。代价是撤销后的画板并非某个历史时刻的精确复原。变更统一入口见 ADR 0014。
