# 模型只通过团队网关调用

模型调用只集成团队的 new-api 网关。端点、请求与响应按独立契约验证，不假设兼容 OpenAI 或厂商原生接口，也不提供绕过网关的备用通道。两套协议会扩大测试面并造成行为分叉。

模型能力默认需要真实网关证据。Flash 的官方明确支持能力可在客户端实现和自动化验证齐备后开放；官方支持、网关实测和客户端实现分别记录，合成响应不算新的真实生成或视觉证据。未知协议保持未知，此例外不推广到其他模型。

网关拒绝、坏响应或下载失败明确失败，不自动换模型。Flash 不自动重发生成请求；其他模型的既有 429 策略见 ADR 0015。[网关契约](../contracts/team-gateway-contract.md) 保存协议与夹具的适用范围。
