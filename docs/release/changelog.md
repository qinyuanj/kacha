# 1.6.5

## 修复

- 后台检查更新现在真的会按间隔重复：此前排程只在启动时排一次，检查结束后从不重排，所以「每隔一段时间检查」从未发生，每次启动只查一次。现在启动约 3 秒查第一次，之后每 15 分钟查一次。
- 下载更新期间不再发起新的检查，避免把正在下载的内容丢掉。

## 改进

- 自动更新装完会直接打开 Kacha，不再停在「装好了但没起来」。只对自动更新生效：手动静默安装不会突然弹出应用。
- 恢复应用图标（「相纸叠放」）：程序、任务栏与开始菜单重新显示图标。这个图标在换壳时丢了，程序一直用 Go 的默认图标。
- Seedream 5.5 的拆分图层与文字识别由「待测」改为可用：已在真机验收中确认。Seedream 5.0 pro 的拆分图层保持「待测」——那一次验收没有覆盖它。
- 注意：单份文生图、参考图编辑、透明背景与图层拆分已接通；整理与归档照旧；富文本 OCR 之外尚未接入的能力仍显示尚不可用。

# 1.6.4

## 修复

- 参考图编辑与较慢的模型不再被误报「网络不可达」：提交生成请求改用与查询分开的超时（生成 5 分钟、取结果图 2 分钟、模型发现仍是 20 秒）。此前所有请求共用 20 秒总超时，参考图较大或模型较慢时会在等响应头时被掐断，看起来像网络故障。
- 网络错误消息里的「无法连接网关」不再重复出现两次。
- 注意：单份文生图、参考图编辑、透明背景与图层拆分仍按各自工作流的声明使用，整理与归档照旧；富文本 OCR 等尚未接入的能力仍显示尚不可用。

# 1.6.3

## 修复

- 生成失败时，日志记下具体原因而不是只有「响应无效」这类标签：结果图校验失败会带上实际字节数与开头几个字节，诊断包导出的日志因此能直接分辨拿到的是图片、JSON 错误体还是被截断的内容。界面提示文案不变。
- 注意：单份文生图、参考图编辑、透明背景与图层拆分仍按各自工作流的声明使用，整理与归档照旧；富文本 OCR 等尚未接入的能力仍显示尚不可用。

# 1.6.2

## 新增

- 文生图与参考图编辑接入 Seedream 5.5：可用尺寸、参考图上限与透明背景都按该工作流的声明判定，不再按模型一律处理。真实出图效果待验证。
- 链式编辑默认保持一致性：在上一张结果上继续修改时，默认沿用同一主体与风格，减少多轮之间的漂移。连续三轮以上的真机效果待验证。
- 拆分图层可以设输出张数：声明了张数约束的工作流可在 2–100 之间设置，请求按声明下发 `max_images`；未声明的工作流请求体不变。真机拆层效果待验证。

## 改进

- 拆分场景的参考图约束改读能力表，并在选图时就地拦下：格式、体积、总像素与宽高比不合规的参考图会标黄并写明原因，拖线与提交前用同一套判定，不再等到请求发出才失败。
- 更新状态回到主界面：发现新版本、下载与可安装都在主界面可见，不再只藏在高级设置里；保持空闲时自动保存，没有在途任务才重启安装。真机升级链待验证。
- 依赖没有按 lockfile 装全时，验证脚本先报原因与修复命令（`npm --prefix client ci`）再退出，不再刷出一片假的源码类型错误。
- 内部：发版门禁不再包含变异测试（2026-11-20 决定）。变异工作副本会把本机整机拖崩，uml-viewer 当前也产不出可信的覆盖率产物；CRAP 与重复检查照旧执行，每条质量命令仍会打印「变异测试未启用」与原因，不静默跳过。
- 注意：单份文生图、参考图编辑、透明背景与图层拆分仍按各自工作流的声明使用，整理与归档照旧；富文本 OCR 等尚未接入的能力仍显示尚不可用。上面标「待验证」的能力目前只有自动化用例，尚未完成真机验收。

## 改进

- 注意：1.6.0 的客户端自己升不上来——坏掉的正是它自己的解析逻辑，已经装了 1.6.0 的用户需要手动下载 1.6.1 覆盖安装；1.6.1 及其之后的版本才有正常的自动更新。其余能力与 1.5.0 相同：单份文生图、参考图编辑、透明背景与图层拆分、整理与归档照旧，尚未接入的能力仍然显示尚不可用。

# 1.5.0

## 新增

- Windows 桌面客户端：画板、参考图与设置保存在本机，打开和编辑无需登录。
- 手动导入画板包，带着原有图片和图层继续编辑。
- 截图可直接粘贴进画板，画板图片可复制到其他软件或另存为文件。
- 阶段：把一段迭代框起来起个名字，可以收起、改名、增删成员，也可以只按候选节点自动划分。
- 定稿：把要留的结果标记为定稿，保存重开仍在。
- 整理模式：看到画板和每个阶段有多大，把未定稿结果收掉，或把阶段移出为新画板继续迭代。
- 单份文生图：经桌面端口与本机服务调用团队网关，结果、发送文本与任务记录落在本机任务目录，保存重开后可追溯。
- 参考图编辑：在本机选图或粘贴截图进参考图，按区域指示修改图片；继续编辑、加为参考图与生成变体都在画板上留下连线。
- 透明背景与图层拆分：按模型能力生成透明背景 PNG；Flash 可把结果拆成按 z 序定位的透明图层，重开后底图与图层都在，并可从某一层继续编辑。
- 跨画板任务队列：多块画板共用一条队列并遵守并发上限；份数展开为独立任务、各自一张结果；可以逐份取消，退避中的取消不会卡住其他画板。
- 归档：不再迭代的画板可以归档，只读、不占画板位，随时可以取消归档或复制为新画板。
- 本机用量：查看数据根里的文件占用、设置容量提醒阈值，提醒不会阻止生成。
- 清理与回收：清理前先预览未被引用的任务目录，确认后移入本机回收区并保留 14 天，可自行恢复。
- 画板包导出：导出完整画板包，把单张结果、图层或整板结果保存到选择的位置。
- 脱敏诊断包：导出排除 API 密钥与凭据的诊断信息，便于反馈问题。
- Windows x64 当前用户安装器：无需管理员权限，带开始菜单入口，卸载默认保留创作数据。

## 改进

- 画板列表显示每块画板大约多大，太大的标黄或标红；正在用的画板太大时会提示整理。
- 自动更新已接通代码路径：启动约 3 秒检查一次、之后每次检查结束约 6 小时再检查，也可随时手动检查；只选更高版本且带齐安装器、签名与更新描述的正式发行；下载完成并验签通过才可安装，安装只由用户点击触发，装前会等在途任务结束并严格保存全部画板。当前构建未内置发布者公钥，因此入口显示「尚不可用」。
- 注意：当前支持本机画板编辑、归档、画板包导出与整理（可编辑画板上限 20，归档画板只读、不占画板位且不因闲置删除）；单份文生图、参考图编辑、透明背景与图层拆分已接通团队网关；安装器可构建，但真实签名发行与双版本升级验收仍需发布凭据与交互环境，见 packaging/RELEASE_163.md 与 RELEASE_164.md。
