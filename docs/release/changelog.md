# 1.5.0

## 新增

- Windows 桌面客户端：画板、参考图与设置保存在本机，打开和编辑无需登录。
- 手动导入画板包，带着原有图片和图层继续编辑。
- 截图可直接粘贴进画板，画板图片可复制到其他软件或另存为文件。
- 阶段：把一段迭代框起来起个名字，可以收起、改名、增删成员，也可以只按候选节点自动划分。
- 定稿：把要留的结果标记为定稿，保存重开仍在。
- 整理模式：看到画板和每个阶段有多大，把未定稿结果收掉，或把阶段移出为新画板继续迭代。
- 单份文生图：经桌面端口与本机服务调用团队网关，结果、发送文本与任务记录落在本机任务目录，保存重开后可追溯。
- 参考图编辑：在本机选图或粘贴截图进参考图，按区域指示修改图片；继续编辑、加为参考图与生成变体都在画板上留下连线。
- 透明背景与图层拆分：按模型能力生成透明背景 PNG；Flash 可把结果拆成按 z 序定位的透明图层，重开后底图与图层都在，并可从某一层继续编辑。
- 跨画板任务队列：多块画板共用一条队列并遵守并发上限；份数展开为独立任务、各自一张结果；可以逐份取消，退避中的取消不会卡住其他画板。
- 归档：不再迭代的画板可以归档，只读、不占画板位，随时可以取消归档或复制为新画板。
- 本机用量：查看数据根里的文件占用、设置容量提醒阈值，提醒不会阻止生成。
- 清理与回收：清理前先预览未被引用的任务目录，确认后移入本机回收区并保留 14 天，可自行恢复。
- 画板包导出：导出完整画板包，把单张结果、图层或整板结果保存到选择的位置。
- 脱敏诊断包：导出排除 API 密钥与凭据的诊断信息，便于反馈问题。
- Windows x64 当前用户安装器：无需管理员权限，带开始菜单入口，卸载默认保留创作数据。

## 改进

- 画板列表显示每块画板大约多大，太大的标黄或标红；正在用的画板太大时会提示整理。
- 自动更新已接通代码路径：启动约 3 秒检查一次、之后每次检查结束约 6 小时再检查，也可随时手动检查；只选更高版本且带齐安装器、签名与更新描述的正式发行；下载完成并验签通过才可安装，安装只由用户点击触发，装前会等在途任务结束并严格保存全部画板。当前构建未内置发布者公钥，因此入口显示「尚不可用」。
- 注意：当前支持本机画板编辑、归档、画板包导出与整理（可编辑画板上限 20，归档画板只读、不占画板位且不因闲置删除）；单份文生图、参考图编辑、透明背景与图层拆分已接通团队网关；安装器可构建，但真实签名发行与双版本升级验收仍需发布凭据与交互环境，见 packaging/RELEASE_163.md 与 RELEASE_164.md。

# 0.2.0

## 新增

- 0.2.0 是 v2 首个发布版本，客户端由 PySide6 重写为 Tauri + React Flow；与 0.1.0 不兼容，需全新安装。
- 画板即主界面：提示词、参考图、生成任务、结果都是画板节点，用连线表达输入来源；支持多画板标签、框选 / 平移、撤销 / 重做与拖线建节点。
- 文生图与图片编辑：生成任务按模型能力露出端口，参考图按「图N」接入，超出输入上限时发送前缩放 / 转码，可查看发送文本。
- 区域指示：在参考图上框出多个矩形，按「区域N」分色并在提示词中指代，叠加图由客户端生成。
- 迭代动作：以此继续编辑、加为参考图、生成变体都留下连线；结果列按时间累积。
- 图层拆分与透明背景：支持的模型可把结果拆成带透明通道的图层，图层可作为后续输入。
- 上架 Seedream 5.0 pro / lite 与 qwen-image-3.0-pro / qwen-image-3.0，按旗舰 / 经济分档；负向提示词按模型能力分流。
- 画板包导出再导入，任务目录保存任务记录与生成结果，画板只引用不持有；缺图可重新定位。
- 高级设置与诊断：网关地址、API 密钥、输出根目录、并发上限默认 4；诊断包导出时脱敏，不含 API 密钥。

## 改进

- 检查更新：启动后向 Gitea 询问最新版本，有新版时顶栏提示，高级设置也可手动检查；当时只提示不自动安装。

# 0.1.0

## 新增

- 面向蛋仔派对与千星 UGC 美术团队的本地图片生成工作台，提供 Windows x64 便携版与 macOS Apple Silicon 版。
- 文生图与图片编辑两个工作流，统一任务中心，并发上限 1～6；未知模型保持禁用。
- 结果保存到本机图片目录，支持保存副本、复制到剪贴板与打开所在目录。
- 内置只读与个人项目预设，个人预设保存在用户数据目录。
- 大小受限的轮转脱敏日志，可预览清单并导出诊断包。

## 改进

- 注意：当时默认网关是明文 HTTP，只允许隔离内网或可信 VPN；API 密钥只保存在 Windows 用户系统凭据库。
- 注意：当时两平台包均无正式签名，首次启动需按系统提示放行；macOS 版仅支持 Apple Silicon。
