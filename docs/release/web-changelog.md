# 1.2.1

## 改进

- 顶栏提示改为只说备份，清理规则移到设置的「用量」里。

# 1.2.0

## 修复

- 改并发上限时，输到一半不会被改掉。
- 读设置失败时，不会再覆盖你保存的设置。
- 断网时，任务不会被误标成「已中断」。

# 1.1.1

## 新增

- 画板列表可以删除画板，图片不会跟着删。误删 14 天内可找管理员恢复。

## 修复

- 提示词里打中文不会再被打断。

# 1.1.0

## 新增

- 「份数」：一次出多张图，每张可单独取消。

## 改进

- 大画板打开、拖动更快。
- 导出画板包前能看到大小，包也更小了。
- 导入画板包更快，可以中途取消。

## 修复

- 提示词里的中文标点不会再重复。

# 1.0.0

## 新增

- Kacha 改成网页版：粘贴 API 密钥就能用，换电脑也能看到同样的画板。
- 参考图直接从本机上传；结果可以单张下载，也可以整板下载。
- 设置里能看用量，清掉不用的旧图。
- 注意：服务端不备份，重要画板请导出画板包。桌面版的画板包可以直接导入。
