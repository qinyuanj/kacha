# 1.3.1

## 修复

- 在提示词中间回车换行或插字时，光标不再跳到末尾。

# 1.3.0

## 新增

- 阶段：把一段迭代框起来起个名字，可以收起、改名、增删成员。
- 定稿：把要留的结果标记为定稿。
- 整理模式：看每个阶段多大，把选中阶段的未定稿结果收掉，或把阶段移出为新画板。
- 归档：不再迭代的画板可以归档，只读、不占画板位，随时可以取消归档或复制为新画板。
- 画板列表显示每块画板大约多大，太大的标黄或标红；正在用的画板太大时会提示整理。
- 用量快满时会提醒，可以从「管理画板」按大小挑出该整理的画板。
- 点顶栏的版本号可以看更新内容，发新版后也会提示。
- 注意：每人最多 10 块可编辑画板，满了要先归档或删掉一块，才能新建或导入。

## 改进

- 顶栏提示改为只说备份，清理规则移到设置的「用量」里。

## 修复

- 导入画板包中途失败时，不会只导入一半。

# 1.2.0

## 修复

- 改并发上限时，输到一半不会被改掉。
- 读设置失败时，不会再覆盖你保存的设置。
- 断网时，任务不会被误标成「已中断」。

# 1.1.1

## 新增

- 画板列表可以删除画板，图片不会跟着删。误删 14 天内可找管理员恢复。

## 修复

- 提示词里打中文不会再被打断。

# 1.1.0

## 新增

- 「份数」：一次出多张图，每张可单独取消。

## 改进

- 大画板打开、拖动更快。
- 导出画板包前能看到大小，包也更小了。
- 导入画板包更快，可以中途取消。

## 修复

- 提示词里的中文标点不会再重复。

# 1.0.0

## 新增

- Kacha 改成网页版：粘贴 API 密钥就能用，换电脑也能看到同样的画板。
- 参考图直接从本机上传；结果可以单张下载，也可以整板下载。
- 设置里能看用量，清掉不用的旧图。
- 注意：服务端不备份，重要画板请导出画板包。桌面版的画板包可以直接导入。
