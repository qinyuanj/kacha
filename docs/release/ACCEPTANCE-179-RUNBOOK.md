## 0. 已知的坑：1.5.1 不存在

本仓版本线是 `1.4.x` → `1.5.0`（`22ecb6b`）→ `1.6.0` → `1.6.1`。**git 历史里没有 1.5.1**，Gitea 上也没有它的安装包（发行只到 `v1.6.0`、`v1.6.1`，再往前是旧的 web zip）。

所以 #150 关闭路径里那句「装 `kacha-setup-1.5.1` 探测包」按字面**无法执行**。两个可行替代，选一个：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A（推荐）** | 用已发布的 `v1.6.0` 安装包当起点，验它能否自动升到 `1.6.1` | 零构建；注意 `1.6.0` 的自动更新解析是坏的，**它自己升不上来**——正好用来验「发现新版」这一步，但装不到 `1.6.1` |
| **B** | 从 `22ecb6b` 构建一个 1.5.0 探测包 | 要改 `mygo.config.ts` 版本号并构建，产出未发布产物 |

**必须先决定用哪个**，否则第一步就走不下去。若选 A，`1.6.0 → 1.6.1` 只能验「发现」不能验「装上」；若选 B，能完整验安装链但要接受一个本地构建包。
