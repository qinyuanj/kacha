### 3a. 顺带必须问清的两件事

这两条只有真实网关能回答，代码侧无法自行判定：

1. **`max_images` 该放哪一层**。官方文档把它和 `text_recognition` 一起放在 `layer_decomposition_options` 里，而当前实现发的是**顶层** `max_images`。真机跑拆分时确认网关接受哪种形状；若只认嵌套，要改实现。
2. **OCR 与拆分的开关能不能真的打开**。两者在能力表里现在都是 `untested`，界面上开关可见但**点不动**（显示「等拆分图层验证后可用」）。这是刻意的：没验过就不谎报支持。真机验证通过后，把 `capabilities.builtin.json` 里 `layer_decomposition` 与 `text_recognition` 一起改成 `supported`，**无需改其他代码**。
