## 核对方法

- `git show <来源>` 逐版读取原文，按「新增 / 改进 / 修复」重排为用户可扫读的一条一句；不新增当时没有的功能描述。
- 一级标题只保留版本号，完整索引由 `client/src/core/changelog.test.ts` 与本表同序守护；解析器同时拒绝重复和乱序。
- 尚未发布版本只允许作为未收录的源码改动存在，正常发行时先取产品版本再写入对应标题；弹窗只显示当前及更早版本。
