## 官方与核心实现

官方参数依据见 [契约来源](seedream-flash-contract.md)。普通生成使用顶层有序 `image` 与精确尺寸，输出必须恰好一个有效结果。默认 URL/PNG/无水印，优化只用 standard。参考图数量、实际快照格式、字节、像素、边长与比例在提交前校验，失败不能退回原始违规字节。HTTP 拒绝含 429 不自动重发或换模型。

高亮叠加紧随原图发送并占名额，坐标模式只发原图，用提示文本的 point/bbox 表达。区域连续编号，输入序号换算覆盖中文图 N 与 Image N；越界引用、非法矩形和展开超限直接拒绝，不截断。提示坐标范围 0 至 999。坐标、多区域、跨图和双语接线使用合成测试，不能冒称实际编辑效果。

透明背景在实际发送快照中恰有一张确认带 alpha 的 PNG 时开放；高亮展开成两张即阻断。透明响应使用真实脱敏 JSON 与合成图片回放，原始图片观察不由替代资产重证。

图层拆分请求 `layer_decomposition:true`，单张 PNG/JPEG，尺寸只用 1K、1.5K、2K 或 auto。响应按 z_index 识别底图和排序，absolute 坐标定位，normalized 范围 0 至 1000。关键定位或任一图层下载/格式校验失败则整体失败。图层与底图共同保存在任务目录，缺图层不回落底图。**没有真实 Flash 图层网关夹具**，相关验证全部是官方契约的合成回放。

Lite 旧任务不自动换模型，旧结果仍可作为参考图使用。旧任务身份不可变，重新生成的发送计划按当前规则重算；模型已经停用时明确失败。
