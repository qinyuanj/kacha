# Kacha（咔嚓）

面向蛋仔派对与千星 UGC 美术团队的单机优先 Windows 客户端，用节点画板组织提示词、参考图和生成结果。画板、图片与设置保存在本机，打开和编辑画板无需登录或连接服务端。

## 使用

运行 `Kacha.exe`。首次启动会建立本机数据根，之后每次启动回到同一份数据。同一台电脑只运行一个实例，重复启动会唤起已有窗口。

当前可以新建、打开、保存和删除画板，编辑提示词与节点，撤销和重做，将截图粘贴为参考图，把画板图片复制到系统剪贴板或另存为文件。可以选择本机目标导出画板包，并把单张结果（含图层）或整板结果保存到指定位置。可归档画板释放画板位（可编辑画板上限 20），有空位时可取消归档或复制为新画板继续编辑；归档画板只读，不因闲置自动删除。高级设置里可以查看本机存储用量、清理未被引用的任务目录，并在回收区里恢复误删的内容。高级设置可以填写团队网关地址并测试连接，保存、替换或清除受 Windows 系统保护的 API 密钥；模型列表只取网关发现与本地能力表的交集，未发现时不以静态清单冒充成功。

单份文生图已通过桌面端口和本机服务接入团队网关，结果与任务记录保存在本机任务目录，保存重开后可追溯；参考图编辑与整理尚不可用，相关入口会明确提示。生成能力仍需联网调用团队网关。切换或清除密钥不会改变本机画板身份，断网时仍可查看和编辑本机画板。

## 迁移本机数据位置

在「高级设置 → 数据位置」点「迁移到其他位置…」，用系统对话框选一个新目录。迁移会把数据根里的全部内容（画板、归档画板、任务目录、导入参考图、设置与受 Windows 系统保护的 API 密钥）整份复制到新位置，逐份校验字节后再原子切换数据根记录，然后重新载入页面；重启后仍回到新位置。

目标必须是空目录，且不能是当前位置、它的子目录或它的上级目录，这些情况会直接拒绝并说明原因。迁移前要先让在途任务结束、打包停下，准备期间新的生成提交会被拦下。旧位置不会被删除也不会被改写：复制、校验或切换失败时数据仍在原位置，可继续使用；新位置上的半份内容会被清掉，不会成为唯一数据来源。界面状态里记着的画板路径随迁移改到新位置，打开的画板、结果与设置重启后仍是同一份。

## 导出诊断包

在「高级设置 → 排障信息」导出诊断包，目标由系统另存为对话框选择。诊断包只含版本、平台、运行状态与有限条数的脱敏日志：API 密钥、鉴权头与凭据文件都不进入日志、诊断包或包内文件名，画板内容、任务目录与画板包也不打包。凭据只报「有或没有」，不报值。取消导出会明确说明，不当作成功；目标不可写或采集失败会报出具体原因，且不改动本机创作数据。

## 导入画板包

从「画板包 → 导入画板包…」选择手动导出的 `.ugcpack`。导入会把画板、任务目录、参考图与图层文件放进本机数据根，同名画板自动改名，已有任务内容冲突时保留原内容并提示。

画板文件本身不含图片，迁入或交接数据请使用画板包。画板包包含完整提示词和任务记录，只应接收或交给可信的人。重要数据请自行备份。

从「画板包 → 导出画板包…」可预览包大小并取消导出；确认后用系统「另存为」选择本机位置，任务目录、参考图、任务记录、底图和图层按包格式 v2 写入。预览弹窗可保存单张结果（带图层时为 zip），「画板包 → 下载整板结果」保存整板结果 zip；取消选择不写文件。

## 开发与构建

桌面壳和本地文件能力使用 Go / MyGo，节点画板使用 React / React Flow。构建、依赖与验证入口见 [构建说明](packaging/README.md)。

产品版本只在 `mygo.config.ts` 声明。[更新说明](docs/release/changelog.md) 描述当前版本的可用能力；[领域词表](GLOSSARY.md) 和 [领域决策](docs/agents/domain.md) 说明画板、任务目录与画板包的语义。
