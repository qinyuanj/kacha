# Kacha（咔嚓）

面向蛋仔派对与千星 UGC 美术团队的内网图片生成工作台。提示词、参考图、生成任务与结果组织在节点画板上；生成请求由浏览器发到团队网关，画板与任务目录按用户保存在服务端。

## 使用 Web 版

打开 **http://lzxsvn:3004/**，粘贴自己的 new-api API 密钥即可进入，无需安装客户端。会话有效期 7 天。同一密钥在不同浏览器看到同一份数据；换密钥会被视为新用户，看不到旧密钥下的画板与结果。

HTTP 仅限可信内网或 VPN 使用。页面不需要系统凭据库，也不再有自动更新、诊断包或桌面安装包。

**服务端不备份；60 天未使用的数据可能被清理，请定期导出画板包。** 画板包含完整提示词与任务记录，不脱敏，只应交给可信的人。

## 从旧桌面版迁移

1. 在旧版 `v0.3.x` 中打开要迁移的画板，选择「画板包 → 导出」；每张要保留的画板分别导出，并另存需要单独使用的结果图。
2. 打开 Web 地址，粘贴自己的 new-api API 密钥。
3. 选择「画板包 → 导入画板包…」，选中旧版导出的 `.ugcpack`。图层文件与 `layers.json` 会一起导入。
4. 打开导入的画板，确认参考图、结果与图层齐全后继续使用。

旧桌面版可以继续使用，但不再发布更新。旧代码与发布材料可从 tag `v0.3.2` 找回。不要只复制 `.ugcboard.json`：它不含任务目录与图片，必须使用画板包。

若已经换过密钥，需要保留旧指纹下的整份服务端数据，请联系管理员按[部署说明](packaging/README.md#换密钥后的管理员迁移)搬移目录；普通旧桌面版迁移不需要管理员操作。

## 主要功能

- 多画板标签页、框选 / 平移、撤销 / 重做、上下文菜单、拖线建节点与悬浮动作条。
- 文生图、图片编辑、区域指示、透明背景、Flash 图层拆分与谱系迭代。
- 浏览器上传参考图、下载单张结果（含图层 zip）或整板结果 zip。
- 画板包导入导出、保存冲突提示、保存失败后重试或先导出。
- 按用户显示存储用量，并可预览、确认清理自己的未引用任务目录。

内置模型与 Lite 停用规则见[领域文档](GLOSSARY.md)及[模型矩阵](docs/model-matrix.md)。

## 已知限制

页面输入接管（#97）在本应用内吞掉了与画板冲突的浏览器默认行为：拖到页面上的文件不会被浏览器打开、顶掉当前页面；Ctrl+S / Ctrl+P / Ctrl+F / Ctrl+O 不再保存网页、打印、页内查找、打开文件；Alt+← / Alt+→ 与鼠标侧键不再后退或前进（映射成系统 APPCOMMAND 的侧键除外，见下）；方向键不再滚页（选中节点时仍是微移）；中键不再启动自动滚动；页面滚到边界不回弹。被拦下的快捷键不弹提示，完整清单在 `client/src/core/pageInput.ts`。

下面这些浏览器不给页面拦，如实记着，不算缺陷：

- **Ctrl+W / Ctrl+T / Ctrl+N**：关标签页、开新标签、开新窗口由浏览器自己处理，页面收不到这些按键。
- **被鼠标厂商软件映射成系统 APPCOMMAND 的侧键**：这类映射不经过页面，页面收不到也拦不住。没被这样映射的侧键可以拦——Chromium 只在侧键松开（`mouseup`）时才认这层拦截，实测见票 #97。

## 部署与开发

管理员从 release 构建目录取服务端程序与 `static/`，复制到部署机即可；目标机不需要 Rust 或 Node。构建、配置、Windows 服务、清理恢复和指纹迁移见[部署说明](packaging/README.md)。

本地开发在 `client/` 运行 `npm run dev`，另起 `server/` 的 `cargo run`；Vite 将 `/api` 代理到 `localhost:3004`。正式部署才执行 `npm run build:release`。
